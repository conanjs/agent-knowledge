# Machine learning learning path: from basics to large language models

## Summary
**TL;DR:** Eleven stages, each built on the ones before: (1) foundations — what learning from data means, loss, gradient descent, overfitting; (2) classical supervised models; (3) data preparation and honest evaluation; (4) unsupervised learning; (5) probabilistic models; (6) deep learning; (7) reinforcement learning; (8) transformers and large language models; (9) generative models; (10) learning theory; (11) applied problem families — time series, recommender systems, causal inference, privacy-preserving machine learning, and speech and audio, each entered from the stages it needs. Running models in production runs alongside from stage 3 on. Each stage lists the docs to read in order, one lab exercise that changes an experiment the docs ran, and a self-check question you should be able to answer before moving on.
**Use this when:** you start learning machine learning, plan a study schedule, want to know which doc to read next, or need to see where one doc sits among the others.
**Not this doc:** setting up the lab → `machine-learning/lab-setup.md`; the topic's scope → `machine-learning/index.md`.

## Scope
Covers every doc in `knowledge/machine-learning/` (123 docs in 17 subtopics, plus the lab). Order follows dependencies: a stage only uses ideas from earlier stages, except where a row says otherwise. Every doc's experiment embeds its full script, so each lab exercise starts by copying that script into the lab and changing one thing. External resources are free. Topics this knowledge base does not cover yet are listed at the end.

## Lookup notes
- Every lab output comes from one machine (Apple M2, macOS 26.1) with the versions in `machine-learning/lab-setup.md`; numbers can differ in the last digits on other machines or versions, and wall-clock timings always differ.
- Stage 8's alignment doc uses PPO from stage 7; stage 9's families doc compares against the autoregressive language models of stage 8; stage 10 reads best after stage 6, because double descent and the random-label experiment use neural networks.
- Stage 11's four groups are independent: start any of them once its listed stages are done. The recommender group's two-tower model and the privacy group's DP-SGD use stage 6's PyTorch training loop; the causal group uses stage 5's probabilistic reasoning and stage 3's cross-fitting.
- The math-notation reference in stage 1 defines every symbol the other docs use; keep it open while reading.

## Takeaways
- Follow the stages in order; each stage only uses ideas from the earlier ones.
- Run and change one experiment per stage, and answer the self-check, before moving on.
